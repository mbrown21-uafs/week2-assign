	<h1>Web Systems Course Overview</h1>
	
	
<p>
Welcome to CSCE 20303: Web Systems. This course introduces the foundational 
technologies used to build modern web applications, 
focusing on client-side markup, style, and server-side execution.
</p>

<img src="web-architecture.png"
     alt="Client-Server Architecture Diagram">

<h2>Course Learning Objectives</h2>

<p>By the end of this semester, you will be able to:</p>

<ul>
	<li>Structure web documents using semantic HTML5.</li>
	<li>Style and lay out web pages using CSS.</li>
	<li>Build dynamic client-side applications with JavaScript.</li>
	<li>Understand client-server architecture and HTTP request cycles.</li>
</ul>
